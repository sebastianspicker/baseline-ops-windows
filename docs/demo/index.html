PowerShell audits for Windows endpoints

52 capability scripts, run from a JSON profile you review first. Audit is the default; changes need explicit confirmation.

PowerShell

PS> pwsh -NoProfile -File .\scripts\00-Run-Profile.ps1 `
  -ProfilePath .\examples\profiles\baseline-audit.json `
  -RootPath . -Mode Audit -OutputFormat Json

Choose a profile

A profile is a JSON list of capabilities, run in order. Read every step before you use it on an endpoint.

These examples require no signature and pin no hashes. Configure either before trusted deployment.

    Boundaries
    
        
    
          
    
            
    Audit by default
    
            
    
              Remediation needs -Mode Remediate on the runner
              command, and state-changing capabilities confirm through
              ShouldProcess. A profile cannot turn it on.
            
    
          
    
          
    
            
    Profiles are untrusted data
    
            
    
              They select scripts and order. They cannot choose executables,
              arguments, privileged output paths, or network endpoints.
            
    
          
    
          
    
            
    No shell
    
            
    
              Native tools run through one module that resolves the exact
              executable, keeps every argument token, and limits output and
              duration.
            
    
          
    
          
    
            
    Code checked before elevation
    
            
    
              Elevated runs verify the protected root, owner, ACLs, and reparse
              points of the loaded code. Signature and hash checks apply when
              the profile or command requests them.
            
    
          
    
          
    
            
    Results are evidence
    
            
    
              Exit 0 OK, 2 WARN, 1 FAIL.
              JSON keeps every field. Treat results as sensitive endpoint data.
            
    
          
    
        
    
        
    
          Not claimed: the source files are not Authenticode-signed, and
          RequireSigned checks a certificate chain, not the
          publisher. Verify the release first.
